# Vision

NODO CORE is an **intelligent operating layer** for a person and their business. The user expresses intent;
NODO decides execution: which memory to consult, which agent to involve, which tool to call, which model to use,
and whether an action needs approval.

## North star
> "Nodo, buongiorno. Cosa abbiamo oggi?" — and NODO actually knows.

Voice, text and the visual interface are three doors into the **same** intelligence. Voice is a first-class
interface, not a transcription button.

## Principles
1. **Model-agnostic.** Providers are compute. NODO's identity lives in the Core: memory, context, orchestration, policy.
2. **Intent in, execution out.** The user never chooses models, agents or databases.
3. **Grounded.** NODO distinguishes KNOWN / INFERRED / UNKNOWN and says "I don't have enough information".
4. **Free-first, privacy-first.** Never spend silently; never send sensitive data to a disallowed provider.
5. **Traceable.** If the UI says an agent ran, an `AgentRun` exists. If a graph is shown, the edges are stored.
6. **Seams over speculation.** Build what V0.1 needs; leave clean interfaces for what comes next.
7. **Calm identity.** Concise, competent, proactive, non-theatrical.

## What NODO becomes
Project Pulse, daily briefing, approval center, knowledge graph, local Nodes with wake word and private
inference, coding-agent orchestration, automations (trigger → conditions → actions), and a distributed yet
single NODO across cloud, desktop, server and phone. The roadmap in `ROADMAP.md` sequences this.
